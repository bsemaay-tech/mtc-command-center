## Defect

`MTC_COMMAND_CENTER/11_TRIAGE/overnight_orchestrator.py::write_runner_extension` interpolated a
multi-line `{imports}` block into an f-string before `textwrap.dedent`. Only the first import line
carried the 8-space template indent; lines 2..19 sat at column 0, so `dedent` found a common
prefix of zero and stripped nothing. The emitted
`MTC_COMMAND_CENTER/03_QUANTLENS/tools/overnight_extended_run.py` therefore began with 8 spaces and
did not compile.

## Fix (minimal diff)

`MTC_COMMAND_CENTER/11_TRIAGE/overnight_orchestrator.py`, `write_runner_extension`:

```diff
-    imports = "\n".join(
+    # Join with newline + 8 spaces so every import line carries the same indent as
+    # the template body below; the f-string is interpolated BEFORE textwrap.dedent,
+    # and a single unindented line would stop dedent from stripping anything.
+    imports = "\n        ".join(
```

Everything else in the module is byte-identical. The committed artifact was regenerated by calling
`write_runner_extension(True)` from the fixed module.
