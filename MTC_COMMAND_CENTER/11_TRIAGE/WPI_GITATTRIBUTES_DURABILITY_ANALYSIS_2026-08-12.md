## Exposure statement

### Uncovered LF-only tracked artifacts

On a fresh Windows clone with the measured `core.autocrlf=true`, Git treats these as text under the root rule and writes CRLF. Each LF-only newline gains one CR byte, so the byte count and SHA-256 in the inventory change deterministically.

- RP6, RP7, `run_p0.sh`, `run_ro.sh`, and the three remote `*.sh` files: the identity break is **SILENT at checkout**; execution is normally **LOUD** (`/bin/bash^M`, token/grammar differences, or a published SHA check). The current accepted identities cited in the WP-I table break immediately.
- `transport_runner.ps1`: **SILENT identity break**; PowerShell may continue to execute it, so runtime success is not identity evidence.
- `TRANSPORT_PLAN.tsv`, all accepted Markdown/status/self-QA/prereg documents, and the accepted prereg `.gitattributes`: **SILENT** until an explicit byte/hash comparison. SEC102 residual 41 is exactly this class: `STATUS_SEC102.md:42-45,934-940` says the accepted assertion is against the on-disk document and the scoped protection does not cover the other pinned artifacts.
- The 170 tracked LF-only WP-L evidence members: **SILENT** as a historical evidence-integrity break until an explicit digest verification; any later `sha256sum -c`/manifest check becomes **LOUD**. Scripts may also fail loudly if executed, but their frozen-evidence SHA has already changed before execution.

### Uncovered paths whose Windows bytes would not change

- `SELF_QA_PATHSCOPE.md` and WP-L `03_TRANSPORT/operator_record/ops/10.stderr` are already CRLF; an `autocrlf=true` checkout happens to reproduce that EOL form. The failure is **SILENT** until a hash check.
- The 24 tracked WP-L files with no LF or CR bytes do not change under newline conversion, but remain governed only by heuristics. Pinning the closed mixed-content evidence tree as raw bytes removes that unnecessary dependency.

function Get-RawManifest([string[]]$Paths) {
  foreach ($p in $Paths) {
    if (-not (Test-Path -LiteralPath $p -PathType Leaf)) { throw "missing: $p" }
    $b = [IO.File]::ReadAllBytes((Resolve-Path -LiteralPath $p))
    $sha = [Security.Cryptography.SHA256]::Create()
    try { $hex = ([BitConverter]::ToString($sha.ComputeHash($b))).Replace('-','').ToLowerInvariant() }
    finally { $sha.Dispose() }
    $lf=0; $crlf=0; $lone=0
    for ($i=0; $i -lt $b.Length; $i++) {
      if ($b[$i] -eq 10) { $lf++; if ($i -gt 0 -and $b[$i-1] -eq 13) { $crlf++ } }
      elseif ($b[$i] -eq 13 -and ($i+1 -ge $b.Length -or $b[$i+1] -ne 10)) { $lone++ }
    }
    [pscustomobject]@{ Path=$p; Bytes=$b.Length; LFOnly=$lf-$crlf; CRLF=$crlf; LoneCR=$lone; SHA256=$hex }
  }
}
