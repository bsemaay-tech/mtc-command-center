## Decision frame

The target is the optimizer-independent `TrialRecord`: one Parquet row per trial, DuckDB-queryable. The authoritative field groups are:

- **I — identity:** `run_id`, `candidate_id`, `package_hash`, `deployment_identity_hash`, `evaluation_run_hash`, `family_id`, `trial_id`, `param_hash`, `exit_mode`.
- **S — search lineage:** `search_regime`, `preregistered_space_hash`, `trial_index_in_family`, `family_size`.
- **P — parameters:** one typed nullable column per parameter.
- **M — modules:** `modules_enabled[]`, `modules_enabled_count`.
- **F — folds:** `fold_test_returns[]`, `fold_test_sharpes[]`, `fold_test_trades[]`.
- **L — lockbox:** return, Sharpe, max DD, trades, PF, expectancy-R, win rate.
- **B — benchmark:** `bh_return_pct`, `excess_alpha`.
- **St — statistics:** `dsr_p_value`, `dsr_robust`, `bh_fdr_survivor`, `cpcv_pass_ratio`, `pbo`.
- **C — costs:** `net_after_slippage_pct`, `fee_bps_used`, `slippage_model_id`.
- **Ln — lineage:** `simulator_class`, `unsimulated_controls_hash`.
- **G — gate:** `classification`, `rejection_reasons[]`.
- **Fl — flags/artifacts:** `is_pareto`, `is_top_k`, `is_robust`, `is_promoted`, `is_pinned`, `has_full_artifacts`.
- **E — environment lineage:** Python version, dependency-lock hash, and OS alongside the hashes.

Sources: `MTC_COMMAND_CENTER/11_TRIAGE/MASTER_ARCHITECTURE_AND_IMPLEMENTATION_BRIEF_2026-08-21.md:1982-2003`, `:2007-2019`; `MTC_COMMAND_CENTER/11_TRIAGE/MASTER_WORK_PACKAGE_AND_PARALLEL_DELIVERY_PLAN_2026-08-22.md:285-300`, `:377-385`.

In the verdict column, **RETIRE** means retire that file/output as an independent trial/trade/result record after its necessary data has moved to the canonical catalog or selected-trial artifact path. It does **not** authorize deletion of a tool, and this package performs no retirement. All actions belong to WP-P0-13 or a later explicitly authorized package.

## Consolidated disposition

1. Make `mega_walk_forward.py` (after WP-P0-20 migration) the single direct `TrialRecord` emitter.
2. Treat CPCV, PBO, robustness and gate scoring as identity-keyed producers/consumers around that row, not standalone catalogs or in-place JSON mutators.
3. Materialize selected-trial trade/equity/intent/level artifacts once, keyed by immutable identity; migrate the useful columns from `reference_producer.py`, the prototype and STG046 debug writers, batch writers and Stage-2/Stage-2B traces.
4. Retire every legacy JSON/CSV result set from authority after migration and verification. This recommendation authorizes no deletion or writer change.
