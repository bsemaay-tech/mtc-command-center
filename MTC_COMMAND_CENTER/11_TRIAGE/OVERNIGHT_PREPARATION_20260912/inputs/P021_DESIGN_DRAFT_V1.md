## Module interface and fail-closed invariants

### External interface

**PROPOSED interface:** one eligibility module accepts a frozen evidence identity, frozen dataset manifest, target state, owner-ratified `check_set_version`, injected evidence producers, and an injected UTC clock, and returns one immutable `EligibilityVerdictSet`. It performs no admission or lifecycle write. This keeps all check implementation and per-check adapters behind one result interface while preserving the package's measure-only authority. (`MTC_COMMAND_CENTER/contracts/mtc_contracts/admission.py:49-66`; `MTC_COMMAND_CENTER/11_TRIAGE/MASTER_WORK_PACKAGE_AND_PARALLEL_DELIVERY_PLAN_2026-08-22.md:519-525`)

The module must enforce the following invariants before returning a verdict set:

1. Construct WP-P0-04 models through validated entry points; do not use `model_construct()` or another validation bypass. (`MTC_COMMAND_CENTER/contracts/README.md:18-35`)
2. Every result uses exactly one registered check id and a check-specific, versioned `threshold`/`measured_value` shape from this draft. The accepted contract currently types both values generically, so WP-P0-21 owns their narrower interface. (`MTC_COMMAND_CENTER/contracts/mtc_contracts/admission.py:28-39`)
3. `threshold = null`, a missing required threshold member, an unavailable producer, or `dataset_hash = null` prevents `PASS` and produces `BLOCKED` with a named `blocked_reason`. (`MTC_COMMAND_CENTER/11_TRIAGE/MASTER_ARCHITECTURE_AND_IMPLEMENTATION_BRIEF_2026-08-21.md:1397-1401`)
4. Each result's `deployment_identity_hash` and environment lineage must match its verdict set. Evidence from a different deployment identity is refused rather than transferred. (`MTC_COMMAND_CENTER/11_TRIAGE/MASTER_ARCHITECTURE_AND_IMPLEMENTATION_BRIEF_2026-08-21.md:1399-1401`; `MTC_COMMAND_CENTER/contracts/README.md:39-42`)

## Check catalogue

### `P021.DETERMINISTIC_REPLAY`

- **Measures:** whether two clean executions over the same frozen bars, config, and seed produce equal SHA-256 hashes of the complete intent-stream bytes. The binding rule is two runs and any byte difference is a failure. (`MTC_COMMAND_CENTER/11_TRIAGE/MASTER_ARCHITECTURE_AND_IMPLEMENTATION_BRIEF_2026-08-21.md:1390`; `MTC_COMMAND_CENTER/11_TRIAGE/MASTER_ARCHITECTURE_AND_IMPLEMENTATION_BRIEF_2026-08-21.md:1840`)
- **Threshold object:** `{"run_count":2,"intent_stream_hashes_must_equal":true}`.
- **Measured-value object:** `{"run_a_intent_stream_hash":"sha256","run_b_intent_stream_hash":"sha256","hashes_equal":true|false,"intent_count_a":int,"intent_count_b":int}`. Stream canonicalization and the concrete kernel-output adapter are `PROVISIONAL-ON-P012`; the equality threshold is binding and is not provisional. (`C:\tmp\LANE_PROMPTS_20260828\LANE_W52_P021_DESIGN.md:9-11`)
- **Outcome:** unequal hash or intent count is `FAIL`; unavailable run, missing hash/config/seed/dataset identity, or unset stream serialization is `BLOCKED`; otherwise `PASS`. The accepted contract binds the result to the deployment identity and environment lineage. (`MTC_COMMAND_CENTER/contracts/mtc_contracts/admission.py:28-46`)
- **Independent sides:** Replay Producer A and Replay Producer B execute in separate clean processes, neither consumes the other's stream, and the comparator only receives their independently hashed outputs. Here a **clean process** means a newly started OS process with a fresh interpreter, no inherited mutable application cache or prior-run output, an explicit working directory and environment allowlist, and the same frozen input/config/seed/dependency identities. The concrete process launcher remains `PROVISIONAL-ON-P012`.

### `P021.LOOKAHEAD_PREFIX`
