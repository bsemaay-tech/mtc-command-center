## What moved and what was built

- Root `AGENTS.md` is a 3,979-byte identity/safety/router contract.
- Root `CONTEXT_MAP.md` is 1,239 bytes and maps every primary path to exactly one of eight stages:
  governance/operations, MTC build, MTC backtest, QuantLens research, dashboard, PineTS parity,
  Bridge execution, or MTC CLI.
- Root `DECISIONS.md` is a 7,271-byte one-line index. The full legacy register moved with Git history
  to `_AI_MEMORY/history/DECISIONS_FULL_PRE_ROUTER_2026-08-25.md`.
- Each stage has exactly the five required local files. Every `AGENTS.md` is below 6 KiB, every
  `INPUTS.md`/`OUTPUTS.md`/`TESTS.md` below 2 KiB, and every `HANDOFF.md` below the 4 KiB hard cap.
- Lazy terminology-only `CONTEXT.md` files exist only for MTC, QuantLens, and Bridge.
- `_AI_MEMORY/GLOBAL_HANDOFF.md` and `NEXT_STEPS.md` moved with `git mv` to
  `_AI_MEMORY/history/`, with search-on-demand banners. Current state was distilled into the relevant
  stage handoffs; the full journals remain intact.
- The former `_AI_MEMORY/START_HERE.md` moved with history intact and was replaced by a compatibility
  pointer to the root router.
- `11_TRIAGE/INDEX.md` is deterministically generated by `generate_index.ps1`, one row per file with
  date, topic, and bounded summary. It is grep-on-demand, never default context.
- `SESSION_LOCK.md` now states the ratified GitHub-claim/checked-mirror model and removes the unsafe
  age/cleanliness takeover heuristic.
