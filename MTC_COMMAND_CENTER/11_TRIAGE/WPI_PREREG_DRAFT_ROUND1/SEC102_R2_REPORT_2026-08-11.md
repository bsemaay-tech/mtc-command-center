## Outcome

Round 2 implements RENDER and FREEZE end to end for the deliberately bounded all-shell
fixture subset and replaces the round-1 prover stub with a real, pinned adapter to the
repaired `pathscope_prover.py`.

The adapter consumes the repaired seven-counter grammar, reconciles all path, endpoint,
and unresolved records, verifies terminal/process agreement, refuses incomplete output,
and maps:

- coverage or any unresolved issue to composite STOP rc 3;
- an outside-allowlist prover REJECT to composite FAIL rc 1;
- only closed, record-conserved lexical scope to composite PASS rc 0.

Every valid result carries `ALLOW-LEXICAL` without upgrading it to host-object proof and
emits symlink and mount non-establishment as explicit residual disclosures with
`control=false`.

The round-1 ALLOCATE implementation and its six RED plus one GREEN fixtures continue to
return their expected rc and reason tokens.

## Implementation shape

RENDER uses one template per member, validates the allocation/consumer conservation
contract, performs exact `{{NAME}}` substitution, compares expected and rendered bytes,
re-identifies the outputs, derives modeled source edges from rendered bytes, and traverses
the derived graph from the entrypoint. Every binding, declared edge, and member receives a
terminal disposition.

FREEZE revalidates allocations, graph, member pins, constants, allowlist, and the exact
approved prover identity. It carries those exact verified byte snapshots into the adapter,
then builds one entrypoint-driven static analysis unit by
replacing each mechanically verified standalone source edge with a modeled readability
operand and the exact pinned child source. The unit is passed to the prover as data and is
never executed; an exact temporary snapshot of the verified prover bytes performs the
parse. Every member, pin, proof input, prover record, and residual receives a terminal
disposition.
