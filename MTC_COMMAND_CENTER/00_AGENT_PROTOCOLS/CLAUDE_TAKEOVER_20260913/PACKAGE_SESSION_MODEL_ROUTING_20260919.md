Token cost sketch per session (Anthropic list prices, Sep 2026): Sonnet 5 ≈ 1/5 of Opus 5 per token; a package session of this shape burns ~2-4 M input tokens (reads + tool output) and ~100-200 k output — on Max these come out of the 5-hour windows, so the cheaper model also stretches the window. Fable for package work would be ~2× Opus with no gain in this recipe-shaped work.
