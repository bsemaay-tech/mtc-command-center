# Fallback Venue Fact Pack — OKX, Binance (Futures), Bybit

**Research cut-off:** 2026-09-15 (Europe/Istanbul)  
**Purpose:** custody/treasury due-diligence record for fallback venues to a small automated, API-driven perpetual-futures operation whose primary venue is Hyperliquid.  
**Scope:** public sources only; no account was opened, created, logged into, or used; no account names, addresses, balances, API credentials or other personal data were accessed.  
**Not advice:** this is a factual research record, not a recommendation and not financial or legal advice.

## Evidence classes

- **VERIFIED** — venue-owned official terms/documentation/help/API/status material, or an official regulator/law-enforcement register/document.
- **REPORTED** — reputable third-party data/report where a primary source is unavailable or the requested item is inherently third-party.
- **UNKNOWN** — the requested fact was not established from the retrieved evidence. Absence from documentation is not treated as proof of absence.
- Binding restrictions and permission rules are quoted where practical. Region-specific sources are identified.
- URLs are plain text in the Source column. Access date for all sources is 2026-09-15.
