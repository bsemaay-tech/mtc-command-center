## 4. What is built tonight (item b, honest scope)
`IBKR_PAPER_BRIDGE/tools/funding_intake_adapter.py` + `tests/test_funding_intake_adapter.py`: a pure, offline converter that reads a `DERIVED_EXTRACTION.json` (+ the run's manifest for the capture-file digests), and emits, deterministically:
1. `binding_packet_draft.json` — the export tool's packet shape with every FILLABLE field filled from the captured bytes and every NOT-FILLABLE field set to the literal `"UNRESOLVED:D-n"` (never a guessed value; a mutant that fills `oracle_price` from arithmetic fails the fence);
2. `retained_rows_expected.json` — the retained-row shape per event (what a v10 store must contain), with `payload_digest` = `"UNRESOLVED:D-1"`;
3. `intake_gap_report.json` — the decision list D-1..D-6 with the field each blocks, counts (events found, fills found, complete-witness rule result), and the statement that the export tool refuses this packet today and why (the exact refusal code the tool would raise: `CANDIDATE_PRODUCTION_EVIDENCE_UNAVAILABLE`).
It never contacts the network, never reads a key, never writes into the capture directory (write-once output dir), and its output is labelled `NONACCEPTING_INTAKE_DRAFT` everywhere. Tests: fixture derived views (the r1 shapes), determinism, refusal of malformed rows, the no-fabrication fence, the completeness rule (a window not hour-aligned → `complete: false`), and a RED arm (fabrication fence removed → test fails).
