Follow root routing, then use the existing task brief: scope and authority -> smallest complete
slice and QA expectation -> implementation -> observed working path -> applicable independent
review/security -> factual handoff. These are seven logical gates, not seven meetings/documents.
Prompts: `../04_SHARED/prompts/05_ai_workflow/00_index.md`.

Classify actual consequence with `../00_AGENT_PROTOCOLS/REVIEW_POLICY.md`, including its activation
boundary and retained package contracts. Preserve existing architecture and accepted decisions; stop polishing plans once the
completion example and sufficient evidence are clear. Do not create work merely to fill lanes.

For repairs, local commits, provider failures and ask-versus-act use
`../00_AGENT_PROTOCOLS/AUTONOMY_AUTHORIZATION.md`. Counters are internal checkpoints. Continue
authorized independent work, change the hypothesis after failure, and keep truthful partial state.
Use the selected HANDOFF at context boundaries; do not rebuild historical memory chains.
